# 怎麼寫一篇教學

在這個資料夾放一個 Markdown 檔，**檔名就是網址**：

```
guides/voice-coding.md   → /guides/voice-coding/
```

檔名建議用英文小寫加連字號，網址比較好貼。寫完 `git push` 就上線，本機先看用 `npm run dev`。

底線開頭的檔案（像這一份）不會被當成文章。

## 開頭的設定

檔案最前面可以放一段設定，三個都可以省略：

```
---
title: 用語音寫程式的三個步驟
date: 2026-11-13
summary: 列表頁上顯示的一句話
---
```

- `title`：沒寫就用內文第一個 `# 標題`，再沒有就用檔名。
- `date`：格式一定要是 `YYYY-MM-DD`。列表依日期新到舊排，沒寫日期的排最後。
- `summary`：列表頁那張卡片上的說明。

## 內文

寫法跟作品介紹文章一樣，見 `content/_怎麼寫文章.md`：標題、段落、清單、引言、程式碼區塊、粗體、斜體、連結、圖片。不支援表格和直接寫 HTML。

圖片放 `guides/img/`，文章裡寫：

```
![這張圖在講什麼](img/檔名.png)
```
