# 怎麼幫作品寫介紹文章

每個公開作品都有自己的一頁：`/work/<專案名>/`。這一頁預設有 logo、一句說明、類型、星數、最後更新、最近的更新紀錄。

想多寫一點，就在這個資料夾放一個 Markdown 檔，**檔名跟 GitHub 的 repo 名稱一樣**（大小寫不用管）：

```
content/SpeakSlow.md      → /work/SpeakSlow/
content/pokkit.md         → /work/Pokkit/
```

寫完 `git push` 就上線。本機先看：`npm run dev`。

底線開頭的檔案（像這一份）不會被當成文章。

## 可以用的寫法

```
# 大標題
## 小標題

一般的段落。**粗體**、*斜體*、`程式碼`、[連結文字](https://example.com)。

- 清單
- 清單

1. 有順序的
2. 清單

> 引言

---（分隔線）

三個反引號包起來的是程式碼區塊。
```

## 放圖

圖片放進 `content/img/`，文章裡寫：

```
![這張圖在講什麼](img/檔名.png)
```

## 不支援的

- 表格
- 直接寫 HTML（會被當成純文字顯示出來，不會生效）

## 連到別的作品

